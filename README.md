# Electronics_Sales_Dashboard_Report
Interactive Excel Sales Dashboard for analyzing Electronics product sales, profits, payment methods, and state-wise performance. Built using Pivot Tables, Charts, Slicers, and Timeline filters to create a dynamic and user-friendly retail analytics dashboard.
## Project Objective
The main objective of this project is to analyze and visualize retail sales data using an interactive Excel dashboard. It helps track product performance, profit trends, payment methods, and state-wise sales to support better business decision-making.
